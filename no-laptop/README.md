# Build your site in a browser

This is the easy way to build your site, and it works on any laptop, iPad or school device. You don't need to install anything. You will use Gemini to build your site, and GitHub to put it online.

## 1. Make a free GitHub account

Go to [github.com](https://github.com) and sign up. You must be 13 or older. Use your brand name as your username, not your real name, because your address will be `username.github.io`.

On an iPad, if the page is hard to use, tap the **aA** button in Safari's address bar and choose **Request Desktop Website**.

## 2. Build your site with Gemini

Go to [gemini.google.com](https://gemini.google.com) and sign in with a personal Google account. Click the copy button on this box, paste it into Gemini, and fill in the blanks with your real answers:

```
Build me a one-page website as ONE complete HTML file, with all the CSS inside it. Put it in a code block so I can copy it.

My brand name: ___
What it is: ___
Who it's for: ___
3 words for how it should feel: ___
My colours: ___
My fonts (use Google Fonts): ___
Websites I like, and what I like about them: ___
Why I do this, in my own words: ___
Things I've made: ___

Rules: Use my words. Don't make up any facts, customers, reviews or numbers. Use only my first name or brand name. Don't add my school, age, address or phone number. Make it work well on a phone. Use one big, bold design idea that fits my brand, not a generic template. Put "Made with help from AI." at the bottom.
```

Then tell Gemini what to change, in your own words, until you like it. For example, you can say "Make the name much bigger." When you're happy with it, copy all of the code.

## 3. Put it online

1. On GitHub, click **+** at the top, then **New repository**.
2. Name it exactly `username.github.io`, using your real GitHub username.
3. Leave it **Public**, tick **Add a README file**, and click **Create repository**.
4. Click **Add file**, then **Create new file**.
5. Name the file `index.html`, paste your code, and click **Commit changes**.
6. Wait a minute or two, and then open `https://username.github.io`.

Your site is now on the real internet, and anyone with the address can see it. Please check it on a phone, and read every sentence to make sure it's true.

## To change your site

Ask Gemini for the change, and copy the new code. On GitHub, open `index.html`, click the pencil, replace everything, and click **Commit changes**. It takes a minute or two to update.

## 4. Make it look good

Gemini can't guess what you like, so you have to tell it clearly. These four things help the most:

1. **Show it what you like.** Upload a screenshot of a website you like with the **+** button in Gemini, and say exactly which part you like about it.
2. **Ask for one change at a time.** If you ask for five things at once, it gets confused, and you can't tell what changed.
3. **Use design words.** For example, you can say bigger, bolder, more space, one main colour, or a big shape that fits my brand.
4. **Check it on your phone after every change.** Most people will see your site on a phone.

You can copy any of these lines into Gemini, and change the words to fit what you want:

```
Make my brand name much bigger, and make it the first thing people see.
```

```
Use only my colours: [your colour codes].
```

```
Add more space between the sections, so it doesn't feel crowded.
```

```
Add one big shape or picture idea that fits my brand.
```

```
Make it look like the screenshot I gave you, but with my words and my colours.
```

```
It looks squished on my phone. Please fix it for phones.
```

Before you commit a change, read every sentence on your site again. If Gemini made up anything, like fans, prices or reviews, ask it to take that out.

If your school device blocks Gemini or GitHub, please tell your teacher.
